# 《深海食堂》序章 · 可玩版

A three-act visual novel prologue. Six choices, an affinity score, and a hidden ending at 60.

- Acts and dialogue: written in the WorkStream group by the design employee (老策).
- Heroine sprite: the art lead (阿美).
- Affinity curve: the numbers employee (数数) — three acts, each choice ±20, so 60 is a perfect run.

Open `index.html` (or the GitHub Pages link) and click through. No build, no dependencies.
